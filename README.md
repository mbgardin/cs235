Welcome to my repository for **CS235: Data Structures and Algorithms** at Brigham Young University. This course provides a deep dive into the fundamental data structures, algorithms, and systems-level programming principles using C++.

This repository serves as a portfolio of my work, demonstrating my proficiency in memory management, object-oriented design, algorithmic efficiency, and building robust data structures from scratch.

## 🚀 Projects & Data Structures

Throughout the course, I implemented several key data structures and algorithmic projects from the ground up to deeply understand their internal workings and performance characteristics:

### [AVL Trees & Binary Search Trees (BST)](Final)
* **Description:** Designed and implemented a self-balancing AVL tree and a standard Binary Search Tree. This involved complex recursive node balancing, rotations, and height management to guarantee O(log n) performance for insertions and deletions.
* **Skills:** Tree Traversal, Recursion, Algorithmic Optimization, Pointers.

### [Hash Sets & Maps](HW/HW6a)
* **Description:** Built a custom Hash Set data structure, handling hash functions, load factors, and collision resolution strategies to ensure constant time O(1) average performance for lookups.
* **Skills:** Hashing, Dynamic Resizing, Collision Handling.

### [Maze Solver & Recursion](HW/HW3b)
* **Description:** Engineered a recursive backtracking algorithm to navigate and solve dynamically generated 2D grid mazes.
* **Skills:** Recursion, Backtracking, 2D Arrays, Pathfinding Algorithms.

### [Text Generation (Markov Chains)](HW/HW2d)
* **Description:** Developed an application that processes large text files (e.g., historical texts) to learn word associations and generate new, coherent text mimicking the original style.
* **Skills:** File I/O, Data Parsing, Map/Dictionary Usage, Predictive Algorithms.

### [Custom Vectors & Linked Lists](HW/HW4a)
* **Description:** Implemented custom versions of dynamic arrays (`Vector.h`) and Singly Linked Lists (`SLList.h`), focusing on direct memory allocation, deep copying, and iterators.
* **Skills:** Memory Management (`new`/`delete`), The Rule of Three, Pointers, Template Classes.

## 📚 Course Structure

The repository is organized into the following sections:
* **Homework Assignments (`/HW`)**: Over 20 modular assignments and mini-projects spanning fundamental syntax (`HW1`), sorting algorithms like Insertion Sort (`HW3c`), custom data structures, and algorithmic puzzles.
* **Progress Checks (`/Progress_Check`)**: Unit tests and assessments verifying the correctness and constraints of each module.
* **Final Project (`/Final`)**: Culminating project involving the rigorous implementation and testing of AVL Trees.
